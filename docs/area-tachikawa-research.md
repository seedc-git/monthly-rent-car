## 1. 調査の結論

立川の検索結果には、特定事業者の地域ページ、実店舗ページ、短期レンタカー予約サイトはあるが、同じ条件で「税・基本保険・CDW・NOC・配車・距離超過」まで分けた中立的な1ヶ月比較がほぼない。

新ページで最も差別化しやすいのは次の3点。

1. 月額基本料金の順位ではなく、総支払額を計算できる比較にする
2. 店舗受取と配送型を分け、立川駅からのアクセスと往復配送料を併記する
3. 立川駅周辺では公共交通も合理的で、市北部・周辺市への反復移動では車の利便性が上がるという地域差を示す

## 6. 地域情報

### 6.1 車が不要な場合も明記する

立川駅はJR中央線・青梅線・五日市線・南武線、多摩モノレールの立川北駅・立川南駅に接続する。立川市地域公共交通計画では立川駅周辺は徒歩利用の割合が高い。

駅周辺に滞在し、目的地も駅沿線なら、駐車場を含む総額と公共交通を比較する。

### 6.2 車の利便性が上がる場合

同計画では、市北部は自動車利用割合が高く、砂川町・柏町・富士見町には比較的広い交通不便地域がある。西砂町・一番町など一部地域ではバス減便も整理されている。

早朝・夜間の通勤、複数目的地の送迎、周辺市への反復移動、荷物や工具の運搬では車を検討しやすい。

### 6.3 法人需要を説明できる公的根拠

- 2021年経済センサス: 民営7,692事業所、従業者115,163人
- 2020年国勢調査: 昼夜間人口比率113.2、多摩26市中1位
- 近隣自治体より支所・支社・支店の割合が高い

期間限定プロジェクト、支店応援、営業、現場巡回などの利用例に結び付けられる。

### 6.4 道路・駐車

立川市の都市計画資料は、広域幹線道路の整備遅れ、市内渋滞、鉄道による地域交通の分断を課題に挙げる。固定の所要時間は掲載しない。

市営北口第一駐車場の全日定期は月30,000円だが、これは一施設の料金例であり、市内の月極相場とは表現しない。

## 8. stagingのインデックス保護

### 確認できた状態

- staging配信元: GitHub Pages、`staging` ブランチ
- サイト内の全HTML: `<meta name="robots" content="noindex, nofollow">` を必須とする既存CIあり
- 新規ページ: `noindex, nofollow` を実装
- `robots.txt`: `Disallow: /`
- 新規 `/area/tachikawa/`: staging sitemapへ追加しない
- canonical: 将来の本番URL
- 本番ブランチ `main`: 今回変更しない

### 未実装

GitHub Pagesではリポジトリ内の`.htaccess`や任意のレスポンスヘッダー設定を使えないため、次はリポジトリだけでは実装できない。

- `X-Robots-Tag: noindex, nofollow`
- Basic認証
- Cloudflare Access

### Cloudflareで保護する手順

権限を持つ管理者が次を設定する。

1. `stg.monthly-rent-car.jp` をCloudflareのプロキシ対象にする
2. Transform RulesまたはWorkerで全レスポンスへ `X-Robots-Tag: noindex, nofollow` を付与する
3. Cloudflare Zero TrustのAccess Applicationへ `stg.monthly-rent-car.jp/*` を登録する
4. 社内メールドメインまたは許可ユーザーだけをAllowにする
5. `curl -I https://stg.monthly-rent-car.jp/` と新規URLでヘッダーを確認する
6. HTMLのmeta robotsとcanonicalが維持されていることを確認する

`robots.txt`のDisallowだけではインデックス防止を完了した扱いにしない。
