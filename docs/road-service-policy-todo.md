# ロードサービス規約・実運用の統一 TODO

更新日: 2026年7月26日

対象: マンスリーレンタカーの貸渡条件、保険・補償案内、CDW加入者向けロードサービス、および事故・故障時の店舗運用

## 背景

立川エリア記事では、現行の店舗運用に基づき「バッテリー上がりを含む車両トラブル時も、店舗へ連絡し、指定ロードサービスの手配について相談できる」と案内する。

ただし、公開中の保険・補償案内と実際のロードサービス運用では、補償対象外事項とロードサービス手配の関係、費用負担、適用条件が十分に区別されていない。本番公開前に、契約文書・公開案内・店舗運用を統一する必要がある。

## 現行規約・公開案内で確認できる記載

- レンタル料金には、対人・対物・人身傷害・車両補償の基本保険料が含まれる。
- CDWは任意加入で、1事故の免責額を補償する制度として案内されている。
- NOCはCDWの対象外とされている。
- レッカー代は利用者負担と記載されている。
- パンク、鍵の紛失、バッテリートラブル等は、保険・補償が適用されない主なケースとして記載されている。
- 事故・故障時は代替車を手配すると案内されているが、在庫、費用、提供距離、同等クラス、所要時間などの条件は公開されていない。
- 公開ページ上では、ロードサービス制度の対象範囲、利用料金、受付時間、距離制限を確認できない。

## 現在の実運用

- バッテリー上がりを含む車両トラブルが発生した場合、利用者は独自に事業者を手配せず、まず契約店舗へ連絡する。
- 店舗が状況を確認し、指定ロードサービスの手配を行う。
- CDW加入者向けのロードサービス制度として運用している。
- 事故・故障時は、状況と在庫に応じて代替車の手配にも対応する。
- 現時点では、ロードサービス費用が常に無料となる条件を公開文書から確定できない。

## 削除または修正が必要な条文・案内

- 「バッテリートラブル等は補償対象外」という記載が、ロードサービスの手配自体も対象外と誤読されないよう修正する。
- 保険・補償の適用可否と、ロードサービスの手配可否を別項目として明示する。
- 「レッカー代は利用者負担」と、CDW加入者向けロードサービス制度の費用負担との関係を整理する。
- 指定ロードサービス以外を利用した場合の費用負担と連絡手順を明示する。
- バッテリー上がり、ジャンピング、パンク、タイヤ交換、ガス欠、脱輪、鍵の閉じ込みなど、対象トラブルを列挙する。
- ロードサービスの受付時間、対応距離、回数上限、無料範囲、利用者負担となる条件を明示する。
- 代替車の手配について、在庫、同等クラス、配送距離、費用、手配時間を保証するものではないことを明示する。

## 本番記事へ「無料」と記載できる条件

次の事項を契約規約・公開案内・店舗マニュアルで統一し、運営責任者と法務確認が完了した場合に限る。

1. 無料となる対象者（CDW加入者など）が確定している。
2. 無料対象となるトラブルの種類が列挙されている。
3. 無料となる作業・距離・回数・時間帯の上限が定義されている。
4. 部品代、消耗品代、燃料代、特殊作業、対象距離外など、利用者負担となる範囲が定義されている。
5. 指定事業者と店舗の手配フローが全店舗で統一されている。
6. 見積書、申込画面、貸渡証、利用規約、Webサイトで同じ条件が表示される。

上記が完了するまでは、記事で「無料」「費用負担なし」「24時間対応」「必ず対応」と断定せず、「指定ロードサービスの手配に対応」「適用条件と費用負担は契約前に確認」と表記する。
